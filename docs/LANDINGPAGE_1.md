# 8. Ada satu konsekuensi penting dari model 2-sided

Kalau ini benar-benar **marketplace**, maka CTA:

> **Request Demo**

saja sebenarnya kurang tepat.

Anda membutuhkan **dua CTA onboarding**:

### Corporate

> **Join as Corporate**

### NGO

> **Join as NGO**

Karena tujuan platform bukan hanya mendapatkan customer SaaS, tetapi **membangun network effect**.

Semakin banyak corporate → semakin menarik bagi NGO.

Semakin banyak NGO/program → semakin menarik bagi corporate.

Itulah yang nantinya menjadi **moat CSRmatics**.

---

# 9. Dan ini membuat model SaaS Anda menjadi menarik

Saya melihat ada kemungkinan CSRmatics akhirnya punya **3 layer**:

### Layer 1 — Intelligence

```text
Company data
CSR programs
ESG
News
CSR signals
NGO data
```

### Layer 2 — Matching

```text
Corporate ↔ NGO
Corporate ↔ Program
CSR Need ↔ Program
```

### Layer 3 — Partnership

```text
Discovery
Introduction
Proposal
Communication
Pipeline
Partnership
Impact reporting
```

Jadi visi besarnya bukan:

> **"SaaS database CSR."**

Tetapi:

> **"Infrastructure for CSR partnerships."**

Itu positioning yang menurut saya **jauh lebih besar dan lebih defensible**.

Kalau arah produknya memang **2-sided marketplace**, saya justru akan menjadikan **"Corporate ↔ NGO matching" sebagai cerita utama landing page**, sementara crawler, AI, vector search, enrichment, dan database ditempatkan sebagai **mesin yang membuat matching itu bisa terjadi**.
