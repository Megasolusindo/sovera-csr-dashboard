# 13. Sitemap dan robots.txt

Saya mencoba mengakses:

```text
/robots.txt
/sitemap.xml
```

tetapi crawler yang saya gunakan tidak berhasil memperoleh kontennya, sehingga **saya tidak akan menyimpulkan bahwa keduanya bermasalah** hanya berdasarkan hasil tersebut.

Ini perlu Anda cek dari server:

```text
https://csrmatics.com/robots.txt
https://csrmatics.com/sitemap.xml
```

Pastikan minimal:

```text
User-agent: *
Allow: /

Sitemap: https://csrmatics.com/sitemap.xml
```

Dan sitemap hanya berisi URL canonical yang memang ingin di-index.

# Kesimpulan audit

**CSRmatics tidak mempunyai masalah fundamental yang membuat saya mengatakan "SEO-nya belum siap".**

Justru sebaliknya.

Homepage sudah mempunyai **semantic content yang cukup kuat**, positioning jelas, dua target audience jelas, dan konsep directory/opportunity yang sangat cocok untuk SEO. ([CSRmatics][1])
